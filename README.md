## Novedades de la versión 4.6

- Corrección visual de la diapositiva 6 del modo presentación.
- Footer institucional rediseñado con la estructura solicitada: identidad institucional + datos del recurso + franja inferior de créditos y versión.

El proyecto es estático y puede publicarse directamente mediante GitHub Pages. Suba el contenido de esta carpeta a la raíz del repositorio y active Pages desde la rama principal.
